## Deploy with GitHub Pages
1. Create a public GitHub repository, e.g. `abhichimmili-portfolio`.
2. Upload `index.html`, `README.md`, `profile.jpg`, and `resume.pdf` (if included) to the repository root.
3. Go to repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Your site URL will look like `https://YOUR-USERNAME.github.io/abhichimmili-portfolio/`.
